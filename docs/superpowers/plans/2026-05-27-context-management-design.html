1. 架构概览

┌─────────────────────────────────────────────────────────────┐ │ Pi Session (raw, immutable) │ │ m0│m1│m2│m3│m4│m5│m6│m7│m8│m9│m10│... (append-only) │ └──────────────────────┬──────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────┐ │ "context" hook (transformContext — every LLM call) │ │ │ │ 1. resolveLatestLensCommand(messages) — 从 history 恢复 lens │ │ 2. isLensCursorValid() — fingerprint 校验 cursor 是否有效 │ │ 3. applyContextLens() — summary + tail │ │ 4. usageForMessages() — 计量 lensTokens / rawTokens │ │ 5. formatUsageNudge() — 超阈值注入提醒 │ │ │ │ → 返回: [summary, ...retainedTail, ?nudgeMessage] │ └──────────────────────┬──────────────────────────────────────┘ │ ▼ LLM Provider

核心思想：Raw session 永不变。Lens 是每次 LLM 调用前的虚拟变换——summary + messages.slice(cursorIndex)。Provider 看到的是压缩视野，session 保留完整历史。

设计参数
compress(focus, filter, guideline)
focus: 自由文本 — 摘要中必须保留的内容
filter: 自由文本 — 可以丢弃/简化的内容
guideline: 一句话 — 核心意图：压缩完要接着干什么

Nudge 默认阈值：60% info / 80% urgent。支持按模型覆盖。 Lens 边界是 compressedThroughMessageCount，一个指向 raw 消息数组的整数下标（不用 AgentMessage.id，因为 Pi 消息没有稳定 ID）。

2. 关键决策

决策理由
Active lens，非 one-shot block Lens 创建后持续生效，直到被新 compress 替换或 clear 关闭。Provider 每个 turn 自动看到压缩视野。
不用 AgentMessage.id，用数组下标 Pi 的 context hook 传入的 message 没有稳定 ID。compressedThroughMessageCount 是指向 raw 消息数组的整数游标。
Cursor 是 array-shape scoped 游标只对创建它的 array shape 有效。Native compaction / fork / tree nav 会改 array shape → cursor 失效。sourceFingerprint 检测 mismatch。
用量按 provider view 算 有 active lens 时，nudge 阈值用 lensTokens（transformed view），因为那是 LLM 实际收到的。
Refresh 是增量的 不反复摘要整个 raw session。Refresh 时输入 = 旧 summary + 旧边界后的新消息。
重入 source of truth = 持久化 tool results 内存 memoryLens 只是 cache。每次 context hook 从 toolResult.details.contextLens 反扫恢复。keep-alive resume / 进程重启可恢复。
摘要必须是语义的 不用占位符。第一次 compress 就用 LLM 生成语义摘要。失败则保持旧 lens + 返回 error。
Native auto-compaction 不是正常控制环 Pi 的 threshold auto-compaction 检查 assistantMessage.usage（lens 后的视野），不是 raw history。所以 raw session 增长不会触发它。Native compaction 只是最后兜底。

3. Pi 管线集成

Pi Agent Loop (each turn): buildSessionContext() ──→ AgentMessage[] │ ▼ transformContext ──→ "context" hook ──→ DeepAgent: apply lens + nudge │ ▼ convertToLlm() ──→ Anthropic/OpenAI Message[] │ ▼ LLM Provider Call │ ▼ AssistantMessage.usage ──→ Pi _checkCompaction(assistantMessage.usage) ↑ │ uses provider usage (lens view) │ → won't trigger from raw session growth

Hook 注册：pi.on("context", handler) — 每次 LLM 调用前自动调用。Extension 运行在 child 模式。

关键事实：Pi threshold auto-compaction 检查 assistantMessage.usage，这是 实际 provider request 的用量。Active lens 在 context hook 中生效，在 provider call 之前。所以正常成功回合的 usage 是 lens 视野的用量，不是 raw session 全量。Raw session 再大，只要 lens 视野不超窗，Pi 就不会触发 auto-compaction。

4. 类型定义

export type ContextMessage = ContextEvent["messages"][number];

export interface CompressParams {
  focus: string;             // 自由文本：摘要中必须保留的内容
  filter: string;            // 自由文本：可丢弃/简化的内容
  guideline: string;         // 一句话：核心意图（压缩完要接着干什么）
  retainRecentTurns?: number;
}

export interface ContextLens {
  version: 1;
  id: string;
  previousLensId?: string;
  summary: string;         // LLM 生成的语义摘要
  params: Required<CompressParams>;
  compressedThroughMessageCount: number;  // cursor into raw[]
  sourceFingerprint: string; // SHA-256 of prefix before cursor
  retainedMessageCountAtCreation: number;
  rawTokensAtCreation: number;
  lensTokensAtCreation: number;
  createdAt: number;
  updatedAt: number;
}

export interface ContextLensCommand {
  version: 1;
  command: "activate" | "clear";
  lens?: ContextLens;
  lensId?: string;
  createdAt: number;
}

export interface NudgeTemplates {
  info?: string;      // ≥60% gentle 提醒模板
  warning?: string;   // ≥70% upgrade 提醒模板
  critical?: string;  // ≥80% urgent 提醒模板
}

export interface ModelContextOverride {
  model: string;           // 模型 ID 或前缀匹配
  budget?: number;
  nudgeThreshold?: number;
  nudgeUrgent?: number;
  nudgeTemplates?: NudgeTemplates;
}

export interface ContextConfig {
  budget: number;              // default: 180000
  nudgeThreshold: number;     // default: 0.6
  nudgeUrgent: number;       // default: 0.8
  retainRecentTurns: number;   // default: 3
  summaryPromptPath: string;   // default: .pi/prompts/context-lens.md
  nudgeTemplates?: NudgeTemplates;
  modelOverrides?: ModelContextOverride[];
}

5. 生命周期

创建 (compress)
Agent calls compress(focus, filter, guideline) ↓ calculateLensBoundary(rawMessages, retainTurns) → boundary index ↓ summarizeForLens(messages[0 .. boundary], params, template) → LLM 调用 → semantic summary ↓ ContextLens { summary, compressedThroughMessageCount: boundary, sourceFingerprint: SHA-256(rawMessages[0..boundary]) } ↓ Store in toolResult.details.contextLens → persisted in session
应用 (every context hook)
resolveLatestLensCommand(messages) → find latest activate/clear ↓ (if activate) isLensCursorValid(raw, lens)? — fingerprint match? ↓ (yes) applyContextLens(raw, lens): [summaryMsg, ...raw.slice(lens.compressedThroughMessageCount)] ↓ (no - fingerint mismatch or clear) return [...raw] — bypass lens (full raw context)
刷新 (compress again)
newBoundary = max(oldBoundary, calculateLensBoundary(now)) ↓ messagesToSummarize = [ oldLensSummary (as user msg), ...raw.slice(oldBoundary, newBoundary) ] ↓ summarizeForLens() → newSummary ↓ newLens = { summary: newSummary, boundary: newBoundary, previousLensId: oldLens.id }
清除 (clear_context_lens)
Agent calls clear_context_lens() ↓ Return toolResult with details.contextLens = { command: "clear" } ↓ Next context hook: resolveLatestLensCommand finds clear → returns undefined ↓ Provider sees full raw context (lens disabled)

6. 上下文计量

两套 token 数字，由 usageForMessages() 每 turn 计算：

指标含义用途
rawTokens 未修改 Pi session 的 token 估算 监控 raw session 体量
lensTokens 变换后 provider view 的 token 估算 nudge 阈值比较

估算方式：estimateMessagesTokens() — 启发式 4 latin chars ≈ 1 token，1 CJK char ≈ 1 token，每条消息 +4 overhead。

Nudge 逻辑：每个 turn 达到阈值后注入一次。阈值可配，模板可覆盖。

级别触发行为模板变量
none< 60%不注入，Agent 上下文干净-
info≥ 60%每次 turn 注入 gentle 提醒{{ratio}}, {{usedTokens}}, {{budget}}, {{level}}
warning≥ 70%每次 turn 注入 upgrade 提醒同上
critical≥ 80%每次 turn 注入 urgent 提醒同上

默认模板（无符号，纯文本，可通过 nudgeTemplates 覆盖）：

info:     "Context at {{ratio}}% ({{usedTokens}} / {{budget}}). Consider using compress to focus the context."
warning:  "Context at {{ratio}}% ({{usedTokens}} / {{budget}}). Tail is growing — refresh the lens with compress soon."
critical: "CRITICAL: Context at {{ratio}}% ({{usedTokens}} / {{budget}}). You MUST call compress NOW."

7. 工具接口

工具功能LLM 何时调用
compress(focus, filter, guideline, retainRecentTurns?) 创建或刷新 active lens。LLM 生成语义摘要。 首次聚焦 / 旧 lens 视野接近预算
context_usage() 报告 rawTokens / lensTokens / 是否该刷新 检查当前状态
clear_context_lens() 关闭 active lens，恢复 full raw context 需要看到完整历史时

8. 安全网 — Native Compaction

正常路径不依赖 Pi auto-compaction。四层保障：

事件行为原因
session_before_compact return undefined — 不注入自定义 compaction Pi 的 firstKeptEntryId 可能和 lens boundary 不同，注入会丢 delta
session_compact 清 in-memory lens + 持久化 clear marker Native compaction 改写了 message array，旧 cursor 不可靠
session_tree 清 in-memory lens + 持久化 clear marker Tree nav 加载新 array shape，旧 cursor 不可靠
session_before_fork 清 in-memory lens + 持久化 clear marker Fork 复制消息到新分支，旧 cursor 在新分支不可靠

Clear marker 通过 pi.sendMessage() 注入，确保 resolveLatestLensCommand 即使在新分支/compacted context 中也能找到它。

9. 重入 & 恢复

Process restart / keep-alive resume: ↓ "context" hook fires ↓ resolveLatestLensCommand(messages) → walks toolResults backwards → finds last { details: { contextLens: { version:1, command:"activate"|"clear", lens:... } } } ↓ if latest = clear → no lens if latest = activate → lens from persisted command ↓ isLensCursorValid() — fingerprint still matches? yes → apply lens no → ignore lens (needs fresh compress)

In-memory memoryLens 是纯 cache。每次 context hook 优先从 persisted tool results 恢复。只有持久化的 lens 里找不到 activate command 时，才 fallback 到 memoryLens。

11. Bug 修复记录

计划审查中发现并修复的问题：

  1. P0 ctx.sessionManager.buildSessionContext() 编译失败
    → 改为 buildSessionContext(ctx.sessionManager.getEntries(), ctx.sessionManager.getLeafId()) + import from @earendil-works/pi-coding-agent
  2. P0 session_before_compact 会用 latest.summary 当 compaction summary，丢 delta
    → 改为 return undefined，让 Pi 默认压缩处理。session_compact 里 clear + persist clear marker。
  3. P1 fork/tree reset 只清 memoryLens，会从 persisted toolResult 恢复旧 lens
    → session_tree / session_before_fork / session_compact 全部加 pi.sendMessage() 持久化 clear marker。
  4. P1 sourceFingerprint 只 hash index + role + toolName + text
    → 加 algorithm version "v2:" + isError + timestamp 字段。hash 截短到 16 hex chars。
  5. P1 retainRecentTurns <= 0 返回 messages.length，有 orphan toolResult 风险
    → Math.max(1, retainRecentTurns) 强制至少保留 1 个 user turn。
  6. P1 ContextUsageSnapshot 缺 nudgeThreshold 字段
    → 新增 nudgeThreshold: number 到类型，usageForMessages() 返回时填入。
  7. P2 summary prompt 构建用手写 extractMessageText 序列化
    → 加 toolCall/toolResult content part 序列化。注：Phase 2 应改用 Pi convertToLlm。
  8. P2 formatUsageReport 无 lens 但 raw 超阈值时说 "No refresh required"
    → 改为 "No active lens — create one with compress to reduce context usage."
